# «Алиф-Ба» — игра: арабские буквы и правила чтения Корана для детей 4–8 лет

Вторая игра рядом с «Аятами вокруг нас»: тот же движок, дизайн, голос рассказчика, имя ребёнка, пауза,
подписка (одна на семью). Адрес: рахмат.рус/igra/alifba/. Цель — ребёнок с нуля узнаёт 28 букв, их вид в слове,
огласовки и основные правила и в конце **сам читает первые слова и аяты Корана**.

## Кто играет и что из этого следует

- Многие дети ещё **не читают по-русски** → всё объясняет голос; задания понятны без текста; любая реплика
  повторяется кнопкой ↻; «Дальше» нажимается само через 3 с.
- Внимание 3–7 минут → глава короткая: 2–4 буквы или одно правило, 3–4 коротких действия.
- Учит **повторение с разнообразием**: одна буква встречается в 5–6 разных мини-играх.
- **Ошибка не наказывается**: неверный ответ мягко объясняется голосом, звёзды — за число ошибок (как в первой игре).
- **Нельзя изображать живых существ** (людей, части тела, животных, птиц, «лица» у предметов). Мнемоники только
  из предметов, растений, природы, геометрии: «Ба — лодочка с точкой под днищем».
- **Без музыки**: только звуки Snd.
- Арабский звук должен быть **правильным** (махрадж). Сейчас — синтез-заглушка; перед запуском все арабские
  звуки записывает человек с правильным произношением (суфлёр, раздел «Арабские звуки»).

## Порядок обучения (по методикам «Каида Нураниййа» / «Нур аль-Баян», упрощено для малышей)

Буквы идут **семьями по форме** — так проще запомнить различие точками.

| Уровень | Глава | Что узнаём |
|---|---|---|
| 1. Буквы | 1 | ا ب ت ث — палочка и лодочки; точки различают буквы |
| | 2 | ج ح خ — крючки |
| | 3 | د ذ ر ز — уголки и горки |
| | 4 | س ش ص ض — зубчики и петельки |
| | 5 | ط ظ ع غ |
| | 6 | ف ق ك ل |
| | 7 | م ن ه و ي ء |
| | 8 | Весь алфавит: повторение |
| 2. Буквы в слове | 1 | Буквы держатся за руки: соединяющиеся и 6 «гордых» букв (ا د ذ ر ز و) |
| | 2 | Начало, середина, конец: формы буквы (семья ب) |
| | 3 | Буквы-хамелеоны: ع غ ه ك, сильно меняющие вид |
| | 4 | Найди букву в слове из Корана |

| | 4 | Читаем слоги: все три огласовки |

Бесплатно (как в первой игре): весь уровень 1 и первая глава каждого следующего.

## Строение главы

1. Заставка «Уровень N · Глава M».
2. **Знакомство** (для каждой буквы/правила): большая буква появляется → голос: имя буквы по-русски,
   затем арабский звук; мнемоника-предмет; слово-пример с картинкой-предметом.
3. **Руки**: обвести букву пальцем (как «Шахада» в первой игре) → поставить точки на места.
4. **Игры-закрепления** — 2 разных из набора (см. ниже), каждый раз другая пара.
5. **Мини-вопрос**: голос называет звук → выбрать из 3 букв (choice с `glyph`).
6. Награда: собранные буквы попадают в «Мои буквы» (сокровища).

## Набор механик (без копирования FITRA, все — своё)

| Механика | Суть | Где |
|---|---|---|
| Буква-знакомство | большая буква, нажми — услышь; мнемоника | везде |
| Обведи букву | палец закрашивает букву по пунктиру, справа налево | ур.1, 2 |
| Поставь точки | основа без точек, перетащи 1/2/3 точки сверху/снизу → получи нужную букву | ур.1 |
| Лопни шарики | звучит звук → лопни шарик с этой буквой (шарики — предметы) | ур.1, 3 |
| Поймай букву | буквы падают, корзинкой ловишь только нужную | ур.1 |
| Найди пару | карточки-память: буква ↔ буква, позже форма ↔ форма | ур.1, 2 |
| Поезд букв | вагоны-буквы сцепляются справа налево; «гордые» буквы не дают сцепиться слева | ур.2 |
| Хамелеон | буква меняет вид в начале/середине/конце; перетащи форму на её место в слове | ур.2 |
| Шапочки-огласовки | перетащи фатху/кясру/дамму к букве → слышишь слог | ур.3 |
| Тянем звук | держи палец — долгий звук тянется по дорожке (мадд), отпусти — сукун «останавливает» | ур.4 |
| Двойняшка | шадда: буква «прыгает» дважды | ур.5 |
| Солнце и луна | сортировка слов с аль- в две корзины | ур.5 |
| Читаем по словам | слова аята подсвечиваются, ребёнок нажимает по порядку, звучит чтец | ур.5 |

## Звук

- Рассказчик (русский) — `voice/<голос>/<id>.mp3`, ключи реплик с префиксом `a_` (не пересекаются с первой игрой).
- Арабские звуки — `voice/ar/<id>.mp3` (+ manifest.json), отдельный голос: `ar_name_<буква>`, `ar_<буква>_a|i|u`,
  `ar_<буква>_an|in|un`, `ar_<буква>_sk` (с сукуном после алифа: اَبْ), `ar_<буква>_aa|ii|uu`, `ar_w_<слово>`.
- Слова и аяты из Корана в уровне 5 — чтец Мишари аль-Афаси (как в первой игре, `voice/qari/`).

## Технически

- Папка `alifba/`: index.html, js/data.js (буквы), js/core.js (сцены, механики, звук, уровни), js/l1…l5.js (главы),
  js/lines*.js (реплики). Общие: ../js/engine.js, ../js/pay.js, ../js/main.js, ../css/style.css, ../fonts.
- `window.GAME_ROOT = "../"` — озвучка и API из корня; `window.SAVE_KEY = "alifba_v1"` — своё сохранение,
  имя ребёнка и код подписки — общие.
