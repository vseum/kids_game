# Аяты вокруг нас

Бесплатная игра для детей 4–8 лет о единобожии и основах ислама.

Каждая глава устроена одинаково:
1. Ребёнок сам пробует сделать то, что делает Аллах: удержать птицу в небе, сделать мёд, позвать ветер.
2. Даже с «помощниками» (шарик, веер, вентилятор) ничего не получается.
3. Ребёнок сам приходит к выводу: так может только Аллах.
4. Вопрос с вариантами. Варианты читаются вслух, поэтому играть могут и дети, которые не умеют читать.
5. Аят из Корана: арабский текст, перевод смыслов и запись чтеца.
6. Звёзды за главу и сокровище в сумку.

## Что уже есть
Мир 1 «Кто всё создал?»: главы «Птица в небе» (67:19), «Пчела и мёд» (16:68–69), «Корабль и ветер» (42:32–33).
Остальные миры показаны в меню «Главы» с пометкой «скоро».

## Как устроено
Одна веб-страница без сборки и без библиотек. Её можно открыть в любом браузере или как мини-приложение в Telegram.

| Файл | Что внутри |
|---|---|
| `index.html` | страница игры |
| `css/style.css` | оформление |
| `js/lines.js` | **все реплики** игры (текст, который звучит и показывается на экране) |
| `js/ayat.js` | аяты для карточек |
| `js/engine.js` | основа: голос, звуки, подписи, вопросы, награды, сохранение |
| `js/chapters.js` | рисунки, главы, меню |
| `voice/` | озвучка: один mp3 на реплику, имя файла = ключ реплики |
| `tools/tts.py` | скрипт, который озвучивает все реплики |

Звуки (ветер, волны, жужжание пчелы, всплески) синтезируются кодом прямо в браузере. Музыки в игре нет.

## Запустить у себя
```
python3 -m http.server 8000
```
и открыть http://localhost:8000

## Озвучка
Голос делается бесплатными нейросетями **Silero TTS** и **Piper**. После того как модель скачана, она работает без интернета, без ключей и без оплаты.
```
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install numpy scipy soundfile omegaconf piper-tts
python3 tools/tts.py --all                 # все пять голосов
python3 tools/tts.py --speaker xenia b1    # одна реплика одним голосом
```
- **Голоса:** `xenia`, `baya`, `kseniya` (женские), `aidar`, `eugene`, `alexandr`, `roman` (мужские, Silero), `denis`, `ruslan` (мужские, Piper). Файлы каждого голоса лежат в `voice/<голос>/`, таблица голосов — `VOICES` в `tools/tts.py`.
- **Выбор в игре:** на стартовом экране кнопка «Голос». Там каждый голос можно послушать и выбрать. Голос по умолчанию — `xenia`. Можно открыть игру сразу с нужным голосом: `?golos=aidar`.
- **Неправильное ударение:** добавьте слово в словарь `STRESS` в `tools/tts.py`, знак `+` ставится перед ударной гласной.

Если файла озвучки нет, игра читает реплику голосом телефона.

## Где опубликована
Игра работает по адресу **https://рахмат.рус/igra/**. Домен рахмат.рус подключён к приложению Timeweb Cloud
из репозитория `vseum/jarvis-azata` (сайт-трекер). Игра лежит там в папке `web/igra/`, а `web/server.js` отдаёт её
по адресу `/igra/`. Timeweb пересобирает сайт при каждом пуше в `main`.

**Обновить игру на сайте:**
```
sh tools/publish.sh ../jarvis-azata/web     # копирует игру в ../jarvis-azata/web/igra
cd ../jarvis-azata && git add web/igra && git commit -m "Обновление игры" && git push
```

## Другой вариант: GitHub Pages (бесплатно)
1. На GitHub откройте репозиторий → **Settings** → **Pages**.
2. В «Build and deployment» выберите **Deploy from a branch**, ветку **main** и папку **/ (root)**, нажмите **Save**.
3. Через минуту игра будет доступна по адресу вида `https://<имя>.github.io/kids_game/`.

## Подключить к Telegram
1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте имя и адрес бота.
2. Затем `/newapp` → выберите бота → название, описание, картинка 640×360 → **ссылка на игру** `https://xn--80aa9aonp.xn--p1acf/igra/` (это рахмат.рус/igra/) → короткое имя, например `game`.
3. Игра откроется по ссылке `https://t.me/<ваш_бот>/game`. Её можно отправлять родителям.
4. Чтобы кнопка игры была прямо в чате с ботом: `/mybots` → бот → **Bot Settings** → **Menu Button** → ссылка на игру.

## Как добавить главу
1. Добавьте реплики в `js/lines.js` и аят в `js/ayat.js` (текст аята берите с https://api.alquran.cloud, издание `quran-simple`).
2. Напишите функцию главы в `js/chapters.js` по образцу `chBird` и добавьте её в список `CHAPTERS`, а её `id` — в нужный мир в `WORLDS`.
3. Озвучьте новые реплики: `python3 tools/tts.py --speaker xenia --missing`.
