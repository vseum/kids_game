# Курс «Учусь читать» по «Муаллим сани» (Алиф-Ба)

Алиф-Ба (razumus.ru/arabic) теперь — только этот курс; прежние уровни 1–5 убраны 26.10.2026.

## Устройство
| Что | Где |
|---|---|
| Уроки: страница книги, буквы, где образуется звук (текст книги), строки упражнений, пары «Обратите внимание» | `alifba/js/ms_data.js` (общие с будущим курсом для взрослых) |

Миры: 1 — уроки 1–6 (бесплатно целиком), 2 — уроки 7–11, 3 — уроки 12–16 (первые главы миров 2 и 3 тоже бесплатны).

Урок: буква (название, на что похожа) → схема рта и строка книги «где образуется» → обвести букву → первая строка: слушаем, потом каждую строку читаем сами и проверяем нажатием → пары «Обратите внимание» → проверка на слух (3 вопроса) → буквы в копилку.

## Звук слов
`/home/user/ttsenv/bin/python tools/ms_audio.py [--recheck] [--force] [--only REGEX]`
1. Слово есть в Коране буква в букву — живая пословная запись чтеца quran.com. Номер файла считается по настоящим словам аята (у API знаки паузы ۚ ۖ сдвигают номер).
2. Иначе — синтез Microsoft (Zariyah / Hamed). Одно слово синтез часто читает «с остановкой» и глотает конечную огласовку, поэтому второй вариант — «слово слово» с отрезанием первого по разметке фонем.
3. Каждый вариант проверяет распознаватель фонем (wav2vec2-xlsr-53-espeak): согласные и конечная огласовка — строго, одна неточность гласной допускается в длинных словах. Не прошёл ни один — звука нет, слово в суфлёре в группе «Муаллим: нет звука».

Живая запись в суфлёре (раздел «Арабские звуки») сразу заменяет синтез: сервер razumus кладёт её в `voice/ar` и добавляет в список звуков. Записанное пометить в `ms_audio_src.json` как «запись» — тогда `--recheck` его не тронет.
